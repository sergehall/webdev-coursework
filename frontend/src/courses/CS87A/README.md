# CS 87A — Python Programming

Santa Monica College Python coursework (Fall 2020). The portfolio presents six
assignments covering basic syntax, collections, file processing, classes, and a
Tkinter desktop interface.

[`CS87A.tsx`](CS87A.tsx) and [`assignments/`](assignments/) implement the course
pages. Downloadable Python sources, assignment PDFs, screenshots, and the two
election datasets live in
[`frontend/public/course-materials/CS87A/`](../../../public/course-materials/CS87A/)
by module. For example, Module 5 contains `A05.py`, `A05ClassPrH.py`,
`house.tab`, and `president.tab`; Module 6 contains `A06.py`. Run those
standalone scripts with an appropriate local Python/Tkinter installation and
keep their expected data files together.

The Module 5 and 6 source files are also used by the course presentation and
playground. Preserve their filenames and companion-file relationships when
changing the downloadable assignment package. Use the
[root README](../../../../README.md) to run the web application.
