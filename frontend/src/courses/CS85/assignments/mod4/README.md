# Module 4B inventory example

`frontend/public/course-materials/CS85/mod-4/show_inventory.php` is offered as
one downloadable PHP file by `Assignment4BContent.tsx`. The assignment asks
students to run that file as `module4b/show_inventory.php` in a local PHP/MySQL
project. Its database setup notes, PDO query, HTML, and inline CSS are part of
that standalone teaching artifact.

The 514-line file was reviewed during the large-file refactoring. Keep it intact
while the single-file download is the course contract. If the assignment later
ships a complete multi-file project, the PHP, template, and styles can be split
together with updated instructions and download links.
