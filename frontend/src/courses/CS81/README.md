# CS 81 — JavaScript Programming

Santa Monica College JavaScript coursework (Summer 2025), covering language
fundamentals, browser scripting, React components, forms, and API interaction.
The course contributed to the broader
[WebDev Coursework Platform](../../../../README.md); this directory is not a
separate frontend or backend workspace.

[`CS81.tsx`](CS81.tsx) is the course entry point. [`assignments/`](assignments/)
holds module exercises, [`components/`](components/) holds course-only demo UI,
[`data/`](data/) holds fixtures, and [`types/`](types/) holds local contracts.
The shared coursework route is in [`AppRoutes.tsx`](../../routes/AppRoutes.tsx).
Static files and the syllabus are under
[`frontend/public/course-materials/CS81/`](../../../public/course-materials/CS81/).

CS 81 choice quizzes use the backend-backed legacy quiz feature. Keep question
data, answer-token behavior, and progress contracts aligned with the
[quiz feature guide](../../features/quiz/README.md) and the
[canonical assessment standard](../../../../docs/quiz-assessment-standard.md). A
browser-only practice runner does not provide a protected exam boundary.

Use the root README for current Node/Yarn versions, installation, scripts, and
deployment configuration. No course-specific installation is required.
