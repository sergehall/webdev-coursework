# CS 80 — Internet Programming

Santa Monica College coursework on HTML, CSS, JavaScript, the Document Object
Model, forms, XML/JSON, and web application development (Summer 2025).

The course entry point is [`CS80.tsx`](CS80.tsx). Interactive assignment screens
live in [`assignments/`](assignments/); course-only form feedback and submission
state live in [`components/`](components/) and [`hooks/`](hooks/). Keep these
helpers here while only CS 80 uses them.

Some exercises are also delivered as standalone files under
[`frontend/public/course-materials/CS80/`](../../../public/course-materials/CS80/).
In particular, Module 3's Strict HTML download and Module 5's form HTML keep
embedded styles and scripts so they can open independently. Changes to those
files need to preserve the download and iframe preview behavior.

This course is part of the [WebDev Coursework Platform](../../../../README.md).
Use the root README for current Node/Yarn versions, installation, scripts, and
deployment configuration. The [course catalog](../catalog/README.md) owns active
course identifiers.
