# Module 4 Cloud Practitioner midterm questions

The two question files hold consecutive ranges from the original 67-question
source. `../module04MidtermQuizQuestions.ts` assembles them in order and keeps
the existing export used by the assessment adapter and tests.

Correct answers remain in `../module04MidtermQuizAnswers.ts`; do not merge them
into the question data or change question wording, option order, or the
multiple-answer flags during structural refactors. The course assessment uses
the shared client-practice runner described in
[assessment standard](../../../../../../../docs/quiz-assessment-standard.md).
