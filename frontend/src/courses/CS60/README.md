# CS 60 — Database Concepts & Applications

Santa Monica College coursework on relational data models, entity-relationship
design, normalization, SQL, and transaction management (Fall 2025). The course's
app implementation is in [`CS60.tsx`](CS60.tsx) and
[`assignments/`](assignments/); the shared route is defined in
[`AppRoutes.tsx`](../../routes/AppRoutes.tsx).

This directory is one course in the
[WebDev Coursework Platform](../../../../README.md). Use the root README for
installation, development, and checks. The assignment screens are portfolio
representations; Canvas course grading, due dates, and external lab environments
are not controlled by this repository.
